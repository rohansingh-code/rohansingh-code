## 🚀 Featured Projects

### 🧠 Nexus — Agentic Medical Intelligence
> *Not a chatbot. A goal-directed reasoning agent.*

A production-grade agentic AI system built on a polyglot microservices stack. Perceives patient intent, plans a resolution path, autonomously invokes tools against live hospital APIs, manages multi-turn session state via Redis, and emits structured action signals — all within a single conversational loop.

`Spring Boot` `Spring AI` `Groq LLaMA-3` `Spring Security` `JWT` `PostgreSQL` `Redis` `Docker Compose` `React`

---

### 📝 ThinkSpace — AI-Powered Thinking Workspace
> *Your thoughts, organized before you finish typing.*

Full-stack MERN notes app that uses Gemini to auto-generate titles, summaries, and tags as you write. Ships with a glassmorphic Obsidian & Amber UI, smart search across content and AI-generated tags, HTTP-only JWT cookies, and a three-tier Upstash Redis rate limiter protecting AI endpoints.

`React 19` `Vite` `Tailwind CSS` `Zustand` `Express` `MongoDB` `Gemini` `Upstash Redis` `JWT`
